## Proyectos

### ABIS-UPC — Sistema Electoral Biométrico
> Proyecto de liderazgo técnico — Universidad Popular del Cesar, 2026

Plataforma modular de votación electrónica con verificación de identidad por huella dactilar (DigitalPersona), reconocimiento OCR de cédulas colombianas, anonimato criptográfico del sufragio (separación irreversible de identidad y voto en tablas distintas via stored procedure ACID) y motor inteligente de asignación de jurados con 7 reglas de negocio en PL/SQL.

**Stack:** Java 21 · Javalin · Python · FastAPI · Oracle XE 21c · C# .NET 4.8 · Node.js · AES-256 / JCEKS
